## Project Overview
Kalahari Roots is a fictional retail store selling South African-made handcrafted home décor (baskets, ceramics, textiles, and wood furnishings), built for the Part 1 "Building the Foundation" website assignment. The site is a static 5-page HTML/CSS/JS site with no backend — forms use client-side validation and a confirmation message only.

## Website Goals and Objectives
- Sell products online to customers beyond the store's immediate geographic area.
- Reduce reliance on manual WhatsApp order-taking by formalising enquiries.
- Build brand awareness around the artisans behind each product.
- Generate qualified product enquiries that convert into sales.

## Key Features and Functionality
- **index.html** — Homepage with hero section, category overview, artisan quote, and call-to-action.
- **about.html** — Organisation story, mission/vision, values, and team.
- **products.html** — Product grid with client-side category filtering (Baskets / Ceramics / Textiles / Furnishings).
- **enquiry.html** — Product/stock enquiry form with validation; auto-fills the product name when linked from a product card.
- **contact.html** — Two store locations (main store + market stall) each with an embedded map, plus a general contact form.
- Responsive layout with a mobile navigation toggle (`js/script.js`).
- Shared design system in `css/style.css` (colour palette, typography, components).
